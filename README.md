# Freelance Development Pricing

I’m an independent developer offering affordable web and app development services.

but I’m also open to larger, more experimental work **if you understand the risks**  
(no refunds, since this is my primary income source).

---

## Static Pages — $60 – $150
Basic websites hosted for free on **GitHub Pages** (no monthly fees).

**Includes**
- 1–3 static pages (extra pages $60 each)
- Simple layout using text, images, and colors you provide
- Up to 2 rounds of revisions
- Final deployment to your GitHub account

**Timeline:** ~3 days total per project  
**Ideal for:** small businesses, artists, personal portfolios, quick demos

**Limitations**
- URL will be like `yourname.github.io`, not `yourname.com`
- No login, database, or user memory (client-side only)
